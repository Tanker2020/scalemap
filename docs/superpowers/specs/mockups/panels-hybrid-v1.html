Making the panels feel like part of the instrument

The scenes (globe, circuit board, racks) got the design treatment; the panels never did. Two directions below, each showing the same three surfaces: the Topology tab, a workload config, and a firewall editor — plus the new examples vault for the home screen. Both keep JetBrains Mono and the existing token palette; they differ in how much they borrow from the scene language versus modern dev-tool ergonomics.

Instrument Rail

The server-view HUD language extended to every panel: luminous section rules, edge-lit rows, values in chips, live micro-bars everywhere. Dense, glanceable, feels like operating a console. Config stays numeric but every number gets a derived consequence beside it.

B

Console Cards

A modern dev-tool feel: roomier entity cards with soft depth, and config through widgets — sliders with live derived hints, segmented controls, preset pickers — so a value's meaning is visible before you commit it. Calmer than A; explains more, glows less. (The cpu-per-request slider below is live — drag it.)
